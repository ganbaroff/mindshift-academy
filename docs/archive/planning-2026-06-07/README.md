# Архив планов, июнь — начало июля 2026

Эти файлы лежали в корне репозитория и читались первыми, хотя описывают продукт,
которого больше нет. Перенесены сюда 2026-08-04, чтобы корень не врал.

**Ни один файл в этой папке не является описанием текущего состояния.** Часть их
утверждений прямо опровергнута кодом — например, `task.md` называет родительское
согласие нереализованным, хотя `src/lib/consent.ts` работает в проде с июля.

Где смотреть правду:

- `AGENTS.md` в корне — карта репозитория и что канонично.
- `docs/canon/MINDSHIFT-PRODUCT-CANON-V1.md` — задуманное поведение продукта.
- `docs/curriculum/MINDSHIFT-RU-CURRICULUM-V1.md` — программа занятий.
- `docs/release/MINDSHIFT-PILOT-READINESS.md` — список дефектов и их решения.
- `docs/PARENT-ACCESS-RUNBOOK.md` — как открывается доступ семье сегодня.

Файлы сохранены целиком: они объясняют, почему продукт стал таким, и это единственная
причина их не удалять.
