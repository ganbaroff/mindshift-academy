# Список субпроцессоров (MindShift Academy)

> **ЧЕРНОВИК — требует подтверждения юриста**  
> Не является утверждённым DPA-пакетом. Дата черновика: 2026-07-31.

| Субпроцессор | Роль в продукте | Категория данных (описание) |
|---|---|---|
| **Microsoft Azure OpenAI** | Тьютор / судья заданий | Инструкции к заданиям в рамках сессии (транзит обработки) |
| **NVIDIA** (Llama Guard и связанные safety-клиенты) | Первичная проверка безопасности | Текст запроса на модерацию (транзит) |
| **Google Gemini** | Независимый слой безопасности | Текст запроса на модерацию (транзит) |
| **Clerk** | Аутентификация родителя/семьи | Email и идентификатор аккаунта |
| **Vercel** | Хостинг приложения | Технические логи платформы (без сырого текста ребёнка в наших метриках) |
| **Turso** | База данных приложения | Прогресс, согласие, коды доступа (хеши), mastery, метаданные |
| **Upstash** | Распределённый rate-limit | Ключи ограничения частоты (не учебный текст) |
| **Resend** | Письма родителю (код согласия, недельные отчёты) | Email родителя; содержание отчёта без сырых детских реплик |

## Примечания пилота
- OpenAI может использоваться для изображения питомца, если ключ настроен; это раскрыто на экране согласия.
- Запрещено для детского пути: сторонние аналитические пиксели, session replay, behavioral profiling, fingerprinting.
