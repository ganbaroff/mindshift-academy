# Протокол инцидента (MindShift Academy)

> **ЧЕРНОВИК — требует подтверждения юриста**  
> Дата черновика: 2026-07-31.

## Порядок действий (оператор)
1. **Freeze** — немедленно выключить внешний ИИ-путь: установить `AI_KILL_SWITCH=1` (детерминированная деградация / choice-mode) и при необходимости откатить деплой Vercel.
2. **Assess** — оценить: затронуты ли данные ребёнка, согласие, кросс-доступ, безопасность контента; зафиксировать факты без копирования сырого детского текста в тикет.
3. **Notify parent** — связаться с затронутыми родителями по каналу оператора; спокойный тон, факты, следующие шаги.
4. **Log** — записать: кто/когда/что сделано/почему; без детских реплик и без PII сверх необходимого.

## Триггер уведомления министерства / регулятора
> **COUNSEL-GATE:** решение о том, требуется ли уведомление государственного органа (включая сценарии для несовершеннолетних в Азербайджане), **не принимается инженером**. Оператор эскалирует CEO + юристу. До письменного указания counsel уведомление министерству **не отправлять**.

## Связанные гейты
Любой инцидент безопасности на пилоте = жёсткая остановка приглашений + этот протокол (`docs/release/MINDSHIFT-PILOT-READINESS.md` §6).
