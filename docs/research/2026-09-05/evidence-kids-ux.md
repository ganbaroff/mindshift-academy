# Evidence base — children's UX, ages 8–11 (research pass, 2026-09-05)

Scope: MindShift Academy, Russian-language browser AI-prompting course for 8–11-year-olds, monster companion, Next.js/Tailwind. Tokens referenced: bg `#FBF1E0`, text `#2B2320`, `--text-muted rgba(43,35,32,.66)`, primary `#FF6B4A`, body 16px, radius ~2xl, buttons `min-h-11` (44px), reduced-motion already respected.

Method: 9 web searches + 9 document fetches against primary/regulatory sources (NN/g, W3C/WCAG, ICO, an academic PDF, Common Sense Media), plus one manual WCAG contrast calculation against MindShift's own tokens. Three fetches were blocked at the source (403/404/undecoded PDF); those rows use the search engine's indexed summary of the same URL instead — see UNVERIFIED.

## Priority implications (top actions, ranked)

1. **Audit `--text-muted` per world theme** (row 11) — only a 0.3 contrast-ratio margin above AA on the base token; the five new light themes (`7e77063`) need the same check against their own backgrounds, not just `#FBF1E0`.
2. **Close the SC 2.2.2 gap** (row 8) — idle/looping motion needs a pause/settle path independent of `prefers-reduced-motion`, since that's a Level A requirement and the OS setting is opt-in, not a page-level control.
3. **Verify celebration/thinking animations are reduced-motion-gated**, not just the idle loop (row 9).
4. **Icon-control hit-area audit** for anything smaller than the 44px button floor (row 6).
5. **Nudge/reward-loop review** against ICO Standard 13 before any streak or "come back" mechanic ships (row 13).
