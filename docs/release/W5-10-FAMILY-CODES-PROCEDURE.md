## Цель
Подготовить операторский чеклист для 10 приглашённых семей Баку. На этом шаге — только процедура и локальные dry-run артефакты без реальных email родителей и без записи в прод.

## Шаг A — allowlist (runbook)
Для каждого родительского email (когда CEO передаст список):

1. Нормализовать: trim + lowercase.
2. Вычислить имя переменной (печатает только digest, не секрет):

```powershell
node -e "const {createHash}=require('node:crypto'); console.log('ACADEMY_ALLOW_EMAIL_'+createHash('sha256').update(process.argv[1].trim().toLowerCase()).digest('hex').toUpperCase())" "parent@example.com"
```

3. **Не выполнять на проде в W5:** `vercel env add …` — только после CEO deploy approval.
4. После env — новый production deployment (CEO gate).

## Шаг B — коды доступа
Когда allowlist на целевой среде готов:

```powershell
# LOCAL rehearsal only — never point at Turso prod
$env:TURSO_DATABASE_URL=$null
node scripts/generate-access-codes.mjs parent1@example.com … parent10@example.com
```

Скрипт печатает ONCE: CODE (ребёнок) + ACTIVATE URL (родитель). Сырые значения не логировать в git/чат.
