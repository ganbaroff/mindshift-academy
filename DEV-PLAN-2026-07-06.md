## 1. WHAT IT IS / ЧТО ЭТО

MindShift Academy is a **children's ADHD tutor** (target kids ~9–14) that teaches prompt-engineering as a 5-lesson game arc (awakening → character → cipher → machine-vision → boss battle). A child chats with an AI "monster pet"; each lesson has a persona, a success rubric, and XP/crystal rewards.

**Verified stack** (`package.json`, source):
- **Framework:** Next.js 16.2.9 (App Router, Turbopack, React 19.2.4) — NOT Next 14; APIs differ from training data.
- **DB:** Prisma 7.8 over libSQL/Turso via `@prisma/adapter-libsql` (`src/lib/prisma.ts:24-27`); schema provider `sqlite`; dev fallback `file:./dev.db`.
- **Auth:** Clerk 7.5.7; invite-only via `ALLOWLIST_EMAILS`, fail-closed in prod (`src/lib/access.ts:20-23`).
- **LLM:** NVIDIA `meta/llama-3.3-70b-instruct` (free tier) → OpenAI `gpt-4o-mini` fallback (`src/lib/ai-provider.ts:3-27`), 12s timeout, maxRetries 0.
- **Rate limit:** Upstash Redis (`src/lib/ratelimit.ts`). **Email:** Resend (weekly-report cron). **Hosting:** Vercel.
- **Payments:** NONE — checkout is a disabled stub ("Payment removed 2026-06-26 — access-by-referral", `src/app/api/checkout/route.ts:3`).

**How to run:**
- Dev: `cd C:\Projects\mindshift-academy && npm run dev` → serves on **http://localhost:3000** (script is bare `next dev`, `package.json:6`; no `-p` override — the stale ":3001" note is UNCONFIRMED / wrong for the dev script).
- Build: `npm run build` (17 routes). Typecheck: `npx tsc --noEmit`. Tests: `npm test` (`node tests/safety.test.mjs`).
- Prod requires `TURSO_DATABASE_URL` + `TURSO_AUTH_TOKEN` or it fails closed at startup (by design).

## 4. WHAT'S BROKEN / ЧТО СЛОМАНО (ranked P0→P3)

### P0 — Lesson 2 is uncompletable: tutor persona contradicts success-gate + UI  *(in-lane fixable — content edit)*
**Which persona SHIPS:** the tutor's live system prompt ships **«солнце»/sun**. Every child-facing surface + the judge ship **«рычи»/roar**. They disagree, so the child cannot win the lesson as taught.
Receipts:
- Tutor persona: `src/lib/curriculum.ts:15` — `systemPrompt: ЕСЛИ он пишет слово "солнце", ТОГДА ты должен радоваться … иначе нейтрально`. Piped live to tutor.
- Success rubric (what the LLM judge grades): `src/app/api/chat/route.ts:110` — lesson 2 = "дал монстру ИНСТРУКЦИЮ … (например «рычи …»)".
- UI hint: `src/app/lesson/[id]/page.tsx:239` — "Добавь в инструкцию слово 'рычать' или 'рычи'."
**Failure:** child follows the visible UI (types «рычи»), but the tutor was told to stay neutral unless it sees «солнце» → the monster's actual reply contradicts the reward the child just earned; if child follows the tutor (types «солнце») the lesson experience is incoherent.
**Fix:** change `curriculum.ts:15` lesson2.systemPrompt to the ROAR/instruction persona so tutor + rubric + UI agree. **CEO note:** `REBUILD-PLAN-2026-07-04.md` reportedly froze the «солнце» concept as canonical plan text (per `AUDIT-FINDINGS-2026-07-04.md:8` — untracked repo docs). Since 5 of 6 surfaces already implement «рычи», aligning to «рычи» is the low-risk resolution, but *which persona is canonical is a content decision* — confirm with CEO before editing the frozen plan text.
