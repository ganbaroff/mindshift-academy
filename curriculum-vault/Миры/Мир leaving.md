# Мир leaving

Монстр дома, собирается на улицу. В прихожей: куртка, ботинки, рюкзак, ключи на полке и закрытая дверь.

**Успех:** счётчик `заперто` дошёл до 1.

**Порядок объявления действий — рабочее решение** (инвариант, проверяется в
`tests/tasks.test.mjs`). Кнопки ребёнку показываются по алфавиту, чтобы порядок не был
подсказкой.

## Действия
| id | кнопка | требует | меняет |
|---|---|---|---|
| `надеть_ботинки` | Надеть ботинки | `ботинки` <= 0 иначе «ботинки уже на мне»; `снаружи` <= 0 иначе «я уже на улице» | `ботинки` +1 |
| `надеть_куртку` | Надеть куртку | `куртка` <= 0 иначе «куртка уже на мне»; `рюкзак` <= 0 иначе «рюкзак уже на спине, куртку через него не надеть» | `куртка` +1 |
| `взять_рюкзак` | Взять рюкзак | `рюкзак` <= 0 иначе «рюкзак уже на мне» | `рюкзак` +1 |
| `взять_ключи` | Взять ключи | `ключи` <= 0 иначе «ключи уже у меня»; `снаружи` <= 0 иначе «я на улице, а ключи на полке в прихожей» | `ключи` +1 |
| `открыть_дверь` | Открыть дверь | `дверь_открыта` <= 0 иначе «дверь уже открыта»; `заперто` <= 0 иначе «дверь заперта, я уже её закрыл» | `дверь_открыта` +1 |
| `выйти` | Выйти | `дверь_открыта` >= 1 иначе «дверь закрыта, выйти сквозь неё я не могу»; `ботинки` >= 1 иначе «я босиком, на улицу так не пойду»; `куртка` >= 1 иначе «на улице холодно, без куртки я не выйду»; `снаружи` <= 0 иначе «я уже на улице» | `снаружи` +1 |
| `закрыть_дверь` | Закрыть дверь | `снаружи` >= 1 иначе «я ещё дома, закрывать дверь снаружи мне рано»; `ключи` >= 1 иначе «ключей у меня нет, дверь так и останется открытой» | `дверь_открыта` -1, `заперто` +1 |

## Счётчики на старте
- `ботинки` = 0
- `куртка` = 0
- `рюкзак` = 0
- `ключи` = 0
- `дверь_открыта` = 0
- `снаружи` = 0
- `заперто` = 0

## Когда шаги кончились, а дела нет
- `ботинки` < 1 → «я так и не обулся»
- `ключи` < 1 → «ключи остались на полке»
- `снаружи` < 1 → «я не вышел»
- `заперто` < 1 → «дверь осталась открытой»

**Успех вслух:** Я одет, на улице, дверь заперта. Порядок шагов был верный.
