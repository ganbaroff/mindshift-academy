# Мир sandwich

Монстр стоит у стола. На столе: два ломтика хлеба, масло, сыр, нож, тарелка.

**Успех:** счётчик `подано` дошёл до 1.

**Порядок объявления действий — рабочее решение** (инвариант, проверяется в
`tests/tasks.test.mjs`). Кнопки ребёнку показываются по алфавиту, чтобы порядок не был
подсказкой.

## Действия
| id | кнопка | требует | меняет |
|---|---|---|---|
| `взять_нож` | Взять нож | `нож` <= 0 иначе «нож уже был у меня в руке» | `нож` +1 |
| `положить_хлеб` | Положить хлеб | `хлеб` <= 1 иначе «ломтиков хлеба больше нет, их всего два» | `хлеб` +1 |
| `намазать_масло` | Намазать масло | `нож` >= 1 иначе «у меня в руке нет ножа, а рукой я масло не мажу»; `хлеб` >= 1 иначе «на тарелке нет хлеба, мазать не на что»; `масло` <= 0 иначе «масло я уже намазал» | `масло` +1 |
| `положить_сыр` | Положить сыр | `хлеб` >= 1 иначе «на тарелке нет хлеба, мазать не на что»; `накрыто` <= 0 иначе «сэндвич уже накрыт сверху, внутрь не добраться» | `сыр` +1 |
| `накрыть_хлебом` | Накрыть хлебом | `хлеб` >= 1 иначе «на тарелке нет хлеба, мазать не на что»; `хлеб` <= 1 иначе «ломтиков хлеба больше нет, их всего два»; `накрыто` <= 0 иначе «сэндвич уже накрыт сверху, внутрь не добраться» | `хлеб` +1, `накрыто` +1 |
| `подать` | Подать | `накрыто` >= 1 иначе «подавать нечего, сэндвич ещё не собран»; `масло` >= 1 иначе «подавать нечего, сэндвич ещё не собран»; `сыр` >= 1 иначе «подавать нечего, сэндвич ещё не собран» | `подано` +1 |

## Счётчики на старте
- `нож` = 0
- `хлеб` = 0
- `масло` = 0
- `сыр` = 0
- `накрыто` = 0
- `подано` = 0

## Когда шаги кончились, а дела нет
- `масло` < 1 → «масло не намазано»
- `сыр` < 1 → «сыр не положен»
- `накрыто` < 1 → «сверху не накрыто»
- `подано` < 1 → «я не подал сэндвич»

**Успех вслух:** Сэндвич собран и подан. Порядок шагов был верный.
