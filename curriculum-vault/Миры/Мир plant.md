# Мир plant

Монстр стоит на подоконнике. Рядом: пустой горшок, мешок земли, одно семечко, лейка с водой и подставка на свету.

**Успех:** счётчик `на_свету` дошёл до 1.

**Порядок объявления действий — рабочее решение** (инвариант, проверяется в
`tests/tasks.test.mjs`). Кнопки ребёнку показываются по алфавиту, чтобы порядок не был
подсказкой.

## Действия
| id | кнопка | требует | меняет |
|---|---|---|---|
| `взять_горшок` | Взять горшок | `горшок` <= 0 иначе «горшок уже у меня в руках» | `горшок` +1 |
| `насыпать_землю` | Насыпать землю | `горшок` >= 1 иначе «мне не во что сыпать, горшка в руках нет»; `земля` <= 0 иначе «земля уже насыпана» | `земля` +1 |
| `выкопать_ямку` | Выкопать ямку | `земля` >= 1 иначе «в пустом горшке копать нечего»; `ямка` <= 0 иначе «ямка уже выкопана» | `ямка` +1 |
| `положить_семечко` | Положить семечко | `ямка` >= 1 иначе «класть некуда, ямки нет»; `семечко` <= 0 иначе «семечко уже лежит в ямке, а оно одно» | `семечко` +1 |
| `закопать` | Закопать | `семечко` >= 1 иначе «закапывать нечего, семечка в ямке нет»; `закопано` <= 0 иначе «я уже закопал» | `закопано` +1 |
| `полить` | Полить | `земля` >= 1 иначе «лить некуда, в горшке нет земли»; `полито` <= 0 иначе «я уже полил» | `полито` +1 |
| `поставить_на_свет` | Поставить на свет | `закопано` >= 1 иначе «нести на свет пустой горшок незачем, семечко не посажено»; `полито` >= 1 иначе «земля сухая, на свету семечко засохнет» | `на_свету` +1 |

## Счётчики на старте
- `горшок` = 0
- `земля` = 0
- `ямка` = 0
- `семечко` = 0
- `закопано` = 0
- `полито` = 0
- `на_свету` = 0

## Когда шаги кончились, а дела нет
- `семечко` < 1 → «семечко так и не легло в ямку»
- `закопано` < 1 → «ямка осталась открытой»
- `полито` < 1 → «земля сухая»
- `на_свету` < 1 → «горшок так и стоит в тени»

**Успех вслух:** Семечко в земле, земля влажная, горшок на свету. Порядок шагов был верный.
